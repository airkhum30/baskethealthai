# baskethealthai
Vision-AI system for grocery basket analysis, health scoring, and healthier product recommendations using YOLOv8.


Dataset Sources: 
Base Training - 
**1. Retail Product Dataset (NIT Patna)**
https://universe.roboflow.com/iit-patna-qg1jh/grocery_items-7i2em

**2. Custom grocery product images collected by the author**
https://app.roboflow.com/rakeshs-workspace-actqh/object_detection_grocery_dataset

Roboflow was used for image annotation, dataset management, preprocessing, and export in YOLOv8 format.
